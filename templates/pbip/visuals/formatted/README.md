# Formatted Visual Templates

visual.json files with real formatting: conditional formatting, gradients, flash themes, bullet patterns, variance charts, SVG image measures.

Use these as copy-paste references when you need specific formatting patterns rather than building from scratch.

## Notable patterns

| File | Pattern |
|------|---------|
| `barChart-bullet.json` | Bullet chart via bar + reference line |
| `barChart-divergent.json` | Divergent bar (positive/negative axis) |
| `barChart-variance.json` | Actual vs target with variance CF |
| `clusteredBarChart-variance.json` | Clustered with conditional variance coloring |
| `card-with-filter.json` | Card with embedded visual-level filter |
| `comboChart-flash.json` | Combo with flash/highlight theme |
| `image-svg-measure.json` | Image visual bound to an SVG ImageUrl measure |
| `kpi-flash.json` | KPI with flash conditional formatting |
| `lineChart-thresholds.json` | Line with reference threshold bands |
| `lineChart-visual-calcs.json` | Line using visual calculations (RUNNINGSUM, RANK) |
| `pivotTable-bullet-kpi.json` | Matrix with bullet chart and KPI columns |
| `tableEx-gradient.json` | Table with gradient conditional formatting |
| `waterfallChart-flash.json` | Waterfall with flash CF on negative bars |

Files ending in `-flash.json` use the Data Goblins flash theme conditional formatting pattern.
