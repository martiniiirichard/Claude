# Default Visual Templates

Minimal visual.json files — theme defaults only, no bespoke formatting.

Use these as a clean starting point when adding a new visual. Copy the file, update the field bindings, and let the theme handle the formatting.

## Files

| File | Visual type |
|------|-------------|
| `advancedSlicer.json` | New slicer (button/dropdown style) |
| `areaChart.json` | Area chart |
| `barChart.json` | Horizontal bar chart |
| `card.json` | Classic card |
| `cardVisual.json` | New card visual |
| `columnChart.json` | Vertical column chart |
| `comboChart.json` | Line + column combo |
| `donutChart.json` | Donut chart |
| `gauge.json` | Gauge |
| `image.json` | Image visual (use with SVG ImageUrl measures) |
| `kpi.json` | KPI visual with target and trend |
| `lineChart.json` | Line chart |
| `pivotTable.json` | Matrix |
| `scatterChart.json` | Scatter / bubble chart |
| `slicer-dropdown.json` | Dropdown slicer |
| `slicer-list.json` | List slicer |
| `stackedAreaChart.json` | Stacked area chart |
| `tableEx.json` | Table |
| `textbox.json` | Text box (titles, labels) |
| `waterfallChart.json` | Waterfall chart |
