Packt workshop materials for production-grade Microsoft Fabric and Power BI design.

| File | Use |
|------|-----|

| `Design Production-Ready Power BI and Fabric Analytics Systems.pdf` | Core reference — production readiness principles |

| `Fabric Production Ready Scoring Worksheet.xlsx` | Scorecard for assessing production readiness |

## When to use

Before making any Fabric architecture decision — workspace topology, capacity SKU, Direct Lake vs Import mode, deployment pipeline design, governance model — check the relevant document here first. These represent current production-grade thinking on Fabric.
