# Fabric Templates

Microsoft Fabric reference materials and notebook examples.

## Subfolders

- **`notebooks/`** — PySpark and Python notebook scaffolding for Fabric Spark compute.
- **`migration/`** — Packt workshop materials for production-grade Fabric architecture, governance, and migration planning.

## When to use

- Starting a Fabric notebook: copy from `notebooks/` and adapt the scaffold.
- Making architecture decisions (workspace topology, capacity sizing, Direct Lake vs Import, deployment pipeline design): reference `migration/` documents before deciding.
- Planning a Power BI to Fabric migration: the migration folder has ADR templates, production readiness scoring, and governance checklists.
